# Dari Langit

Tur satelit tiga dimensi Pulau Lombok dan tiga Gili: Trawangan, Meno, dan Air. Gulir untuk terbang dari langit ke pantai.

## Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:8080`.

## Yang ada di peta

Citra satelit Esri / Maxar, relief medan Mapterhorn, dan kamera yang mengikuti gulir. Ketuk nama pulau untuk loncat, atau **Jelajah** untuk menyeret peta sendiri.
